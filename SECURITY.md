# Security policy

OpsGraph is a synthetic-data portfolio demonstration, not a production or regulated service. Do not upload real customer, employee, payroll, financial, personal, confidential, or regulated information.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting channel for sensitive findings when it is available. Do not place exploit details, credentials, personal data, or confidential material in a public issue. Ordinary non-sensitive bugs can be reported through GitHub Issues.

## Deployment warning

The checked-in token, database password, datasets, and provider defaults are local demonstration values. Anyone adapting this project for a reachable environment must replace development credentials and add authentication, authorization, tenant isolation, managed secrets, rate limits, reviewed data retention, dependency and image scanning, audit controls, and an incident-response process.
